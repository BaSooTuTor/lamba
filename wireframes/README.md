# Wireframes

8 شاشات موبايل (390×844)، عربي RTL، اتعملت في Claude Design. الملفات بصيغة `.dc.html`، وبتتفتح صح جوه Claude Design بس. كل ملف فيه الـ Markup والـ Styles بتاعة الشاشة، فممكن تستخدموه مرجع وانتوا بتبنوا.

| # | الملف | الشاشة |
| --- | --- | --- |
| 1 | `Main.dc.html` | التسجيل واختيار سنة الامتحان |
| 2 | `Home.dc.html` | خريطة الدروس (الدرس 1 مجاني، و 2 و 3 مقفولين) |
| 3 | `Lesson.dc.html` | محاكاة قانون أوم (Sliders للجهد والمقاومة) |
| 4 | `Tutor.dc.html` | السؤال وشرح المدرس الذكي للغلطة |
| 5 | `Paywall.dc.html` | باقة الثانوية العامة 2027 بـ 799 ج |
| 6 | `Checkout.dc.html` | مكان صفحة Paymob الجاهزة (Placeholder) |
| 7 | `Success.dc.html` | تم الاشتراك والإيصال |
| 8 | `Billing.dc.html` | اشتراكي وسجل المدفوعات |

`canvas.json` فيه ترتيب الشاشات على الـ Canvas.
