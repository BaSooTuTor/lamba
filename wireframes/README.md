# Wireframes

18 شاشة موبايل (390×844)، عربي RTL، اتعملت في Claude Design. الملفات بصيغة `.dc.html`، وبتتفتح صح جوه Claude Design بس. كل ملف فيه الـ Markup والـ Styles بتاعة الشاشة، فممكن تستخدموه مرجع وانتوا بتبنوا.

## 0 · الـ Onboarding

| # | الملف | الشاشة |
| --- | --- | --- |
| 0.1 | `Welcome.dc.html` | الترحيب: لمبة، و«لما الفيزيا تنوّر في دماغك»، و 3 مميزات |
| 0.2 | `System.dc.html` | نظام الدراسة: الثانوية العامة متاح، والباقي قريبًا (البكالوريا المصرية، والأزهرية، و IGCSE، والدبلومة الأمريكية، ونظام تاني) |
| 0.3 | `Grade.dc.html` | السنة والشعبة. سنة الامتحان بتتحسب لوحدها (تفاعلي في Play) |
| 0.4 | `Subjects.dc.html` | المواد اللي محتاج يفهمها، والبرمجة (Scratch و Python) كمهارة إضافية قريبًا |
| 0.5 | `Parent.dc.html` | مين هيدفع، وبيانات ولي الأمر للتقرير الأسبوعي (ممكن يتخطى) |
| 0.6 | `Waitlist.dc.html` | قائمة الانتظار لو اختار نظام غير الثانوية العامة |
